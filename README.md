# دودة الأعلام – نشر على Render

## الملفات
- `server.js` — السيرفر (Express + PostgreSQL): حسابات (كلمات سر مشفّرة scrypt)، أسماء فريدة عالمياً، جلسات، حفظ التقدّم، متصدرين حقيقيين، رموز هدية تُستعمل مرة وحدة.
- `public/index.html` — اللعبة (تتصل بالسيرفر تلقائياً).
- `render.yaml` — يجهّز لك الخدمة وقاعدة البيانات بضغطة وحدة.

## خطوات النشر
1. ارفع المجلد كله إلى مستودع GitHub جديد.
2. في Render: **New → Blueprint** واختر المستودع. يسوي لك خدمة `flag-worm` وقاعدة `flag-worm-db` تلقائياً.
3. انتظر حتى تخلص أول عملية بناء، وافتح الرابط. الجداول تنشأ تلقائياً عند أول تشغيل.
4. تأكد من خطة قاعدة البيانات وحدودها في صفحة Render (الخطة المجانية قد تنتهي أو تتوقف بعد مدة).

## تجربة محلية
`npm install` ثم `DATABASE_URL=postgres://... node server.js`

## مهم قبل فتحها للناس
- الشراء بالدولار **معطّل** في وضع السيرفر (`WF_TEST=false`)، ولا تفعّل `ALLOW_TEST_PURCHASES=1` إلا للتجربة.
- الاقتصاد (العملات والخبرة والمشتريات والعجلة والهدية اليومية والإحياء) صار **كله في السيرفر**، انظر القسم التالي.
- أضف سياسة خصوصية وشروط استخدام وسياسة استرجاع.
- جولات اللعب نفسها محلية (لا يوجد لعب جماعي مباشر).

## الدفع عبر Chargily Pay (بطاقات EDAHABIA و CIB)
1. أنشئ حساباً في Chargily Pay، وخذ **Secret Key** من لوحة التحكم (Developers Corner).
2. في Render → خدمتك → Environment: ضع `CHARGILY_SECRET_KEY` و `PUBLIC_URL` (رابط موقعك مثل `https://flag-worm.onrender.com`). اترك `CHARGILY_MODE=test` للتجربة.
3. في لوحة Chargily سجّل رابط الـ webhook: `https://<موقعك>/api/pay/webhook`
4. جرّب الدفع بوضع test. بعدها فعّل الحساب (Account verification) في Chargily، وغيّر `CHARGILY_MODE=live` وضع مفتاح live.
5. عدّل `DZD_PER_USD` (سعر الصرف) أو أسعار `CAT` في `server.js`. تأكد من الحد الأدنى للمبلغ في وثائق Chargily.
- التسليم يتم فقط من السيرفر بعد webhook موقّع (HMAC) ولمرة وحدة لكل طلب.
- هذي البوابة لبطاقات جزائرية. للدفع من خارج الجزائر تحتاج مزود ثاني.

## مزود الدفع الدولي: Lemon Squeezy (بطاقات دولية / PayPal)
1. أنشئ حساب Lemon Squeezy ومتجراً (Store).
2. أنشئ منتجاً بسيطاً (مثلاً "Game credits") بسعر أساسي أي رقم، وخذ **Variant ID**. السيرفر يغيّر السعر لكل عملية بـ `custom_price`.
3. من Settings → API أنشئ **API key**، وخذ **Store ID**.
4. من Settings → Webhooks أضف: الرابط `https://<موقعك>/api/pay/ls-webhook` والحدث `order_created`، وحدد **Signing secret** (أي نص طويل عشوائي).
5. في Render ضع: `LEMONSQUEEZY_API_KEY` و`LEMONSQUEEZY_STORE_ID` و`LEMONSQUEEZY_VARIANT_ID` و`LEMONSQUEEZY_WEBHOOK_SECRET`. اترك `LEMONSQUEEZY_TEST_MODE=1` للتجربة، ثم `0` للحي.
6. راجع شروطهم بخصوص بيع عملات ألعاب/عناصر افتراضية قبل ما تفعّل الحي.
- اللاعب اللي علمه DZ يروح تلقائياً لـ Chargily، والباقي لـ Lemon Squeezy. يقدر يغيّرها من ⚙️ → طريقة الدفع.
- الأسعار والتسليم كلها في السيرفر، والتسليم فقط بعد webhook موقّع.

## الإعلانات (الموقع الرسمي)
- مكان الإعلانات في اللوبي والمتجر + أزرار إعلانات المكافأة (إحياء مجاني 🎬، ×2 العملات 🎬) تظهر **فقط** لما تعبّي `public/ads-config.js` بدوال شبكتك.
- اختار شبكة تقبل موقعك وتسمح بألعاب HTML5 وإعلانات المكافأة، وراجع سياساتها قبل التفعيل.
- للتجربة المحلية فقط: افتح الرابط مع `?dev=1` عشان تشتغل أزرار المكافأة بدون إعلان حقيقي (لا تعلن هذا الرابط للناس).

## أكواد هدايا مجانية
- بيع كروت الهدية معطّل في هذي النسخة. تصنع أكواد مجانية بمفتاح الأدمن:
  `curl -X POST https://<موقعك>/api/admin/code -H "x-admin-key: <ADMIN_KEY>" -H "Content-Type: application/json" -d '{"coins":100,"count":5}'`
- ضع `ADMIN_KEY` في Render (نص طويل عشوائي). كل كود يُستعمل مرة وحدة، واللاعب يدخله من تبويب 🎟️.

## الاقتصاد في السيرفر (سدّ ثغرة الغش)
- العميل (المتصفح) **ما يقدر يعدّل** العملات أو الخبرة أو المشتريات. كل عملية (شراء سكن/علم/قبر/تأثير/معزز، هدية يومية، عجلة، إحياء، نهاية جولة) تمرّ على السيرفر، وهو يتحقق من الرصيد والسعر والوقت ويحفظ داخل معاملة قاعدة بيانات مقفولة (تمنع الطلبات المتزامنة).
- الأسعار والعروض من `catalog.json` (مولّد من كود اللعبة نفسه). لو غيّرت أسعار السكنات في `index.html` ولّد الملف من جديد.
- سكنات وشواهد العروض الحصرية ما تُباع بالعملات إطلاقاً، وتُسلَّم فقط بعد دفع مؤكد من webhook موقّع.
- نتيجة الجولة: اللاعب يرسل نقاطه، والسيرفر يحدد سقفاً حسب مدة الجولة (60 نقطة/ثانية + 500)، ولا يدفع نفس الجولة مرتين، والإحياء بحد أقصى 3 لكل جولة.
- اختبار منطق الاقتصاد بدون أي مكتبات: `node test.js` (17 اختبار).

### حدود لازم تعرفها
- نقاط الجولة ما زالت تُرسل من اللاعب. السقف يمنع الأرقام الخيالية، لكن لاعب يستخدم بوت يلعب بسرعة معقولة ممكن يجمع بالحد الأقصى. لو صار هذا مشكلة تحتاج محاكاة اللعب في السيرفر أو اكتشاف بوتات.
- الجولات النشطة تُحفظ في ذاكرة السيرفر، فإعادة تشغيله تقطع الجولات الجارية (تضيع مكافأتها). وهذا يفترض نسخة سيرفر واحدة.
- مكافأة الفيديو (إحياء مجاني، ×2) يطلبها العميل بعد ما يشوف الإعلان، والسيرفر ما يقدر يتأكد أنه انشاف. الإحياء محدود بـ3 لكل جولة، و×2 مرة وحدة لكل موت.
- ما اختبرت السيرفر مع PostgreSQL حقيقي. اختبرت منطق الاقتصاد (اختبارات الوحدة) والعميل مع سيرفر تجريبي بالذاكرة يستخدم نفس المنطق.

## تشغيل محلي على ويندوز (بدل XAMPP)
اللعبة بنسخة الموقع **تحتاج سيرفر Node**، و XAMPP (Apache/PHP/MySQL) ما يشغّله. لو فتحتها من `http://localhost/...` عبر Apache بيطلع لك خطأ اتصال لأن طلبات `/api/...` ما لها سيرفر يرد عليها.
1. نزّل **Node.js (LTS)** من nodejs.org.
2. قاعدة البيانات PostgreSQL (مو MySQL). أسهل طريقة بدون تثبيت: بعد ما تنشئ قاعدة على Render انسخ **External Database URL**. أو ثبّت PostgreSQL على جهازك.
3. افتح CMD داخل مجلد المشروع:
```
npm install
set DATABASE_URL=postgres://user:pass@host:5432/dbname
node server.js
```
4. افتح **http://localhost:3000** (مو عبر XAMPP).
- للتجربة السريعة بدون سيرفر: افتح `game-site-preview.html` (حسابات محلية بالمتصفح) أو نسخة Poki مباشرة، وتشتغل من XAMPP أو بالضغط المزدوج على الملف.
